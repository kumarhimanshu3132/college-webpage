# Marwadi University - Department Webpage 🎓

[![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)

[![Deployed with GitHub Pages](https://img.shields.io/badge/github%20pages-121013?style=for-the-badge&logo=github&logoColor=white)](https://pages.github.com/)

A static, responsive landing page designed for the Department of Computer Engineering at Marwadi University. This project was developed during Semester 3 as part of the Web Technology curriculum to establish a strong foundation in frontend web development before transitioning to modern frameworks like React.

**🔗 [View Live Demo](https://kumarhimanshu3132.github.io/college-webpage/)**

## ✨ Features
*   **Semantic HTML5:** Proper use of `<header>`, `<section>`, `<nav>`, and `<footer>` tags for accessibility and SEO optimization.
*   **Internal Routing:** Smooth on-page navigation linking directly to specific sections (Vision, Mission, Courses, Recruiters).
*   **Custom CSS Styling:** Implementation of the CSS box model, custom typography, hover effects, and a cohesive university color scheme (#0f4080 and #003060).
*   **Zero Dependencies:** Built entirely with vanilla HTML and CSS without the use of external libraries or frameworks.

## 🛠️ Tech Stack
*   **Markup:** HTML5
*   **Styling:** CSS3

## 🚀 Local Setup Instructions

Since this is a static webpage, running it locally is incredibly simple. No package managers or servers are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/kumarhimanshu3132/college-webpage.git
   ```
Navigate into the project directory:
  ```bash
    cd college-webpage
  ```
2. Open the index.html file directly in your preferred web browser, or use a tool like VS Code's "Live Server" extension for hot reloading.
